Accessibility Statement

Last updated: {{lastUpdatedEn}}

We want Arnaki to be easy for everyone to use, including people with disabilities. This website was built in line with Israel's Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 5773-2013, and Israeli Standard SI 5568, which is based on WCAG 2.0 level AA.

What we've done

  • Pages have a clear heading structure and marked regions (header, main content, footer), plus a "Skip to main content" link.
  • Everything works with a keyboard, with a clearly visible focus indicator.
  • Color contrast meets level AA, and no information is conveyed by color alone.
  • Each page declares its language and text direction (Hebrew right-to-left, English left-to-right).
  • Text can be enlarged up to 200% without losing content, and the layout adapts to small screens.
  • Decorative elements are hidden from screen readers, and all important content is available as text.
  • FAQs use expandable sections that work with a keyboard and screen readers.
  • The site respects your device's "reduce motion" setting and contains no flashing content.

Testing was done in an up-to-date version of Chrome, on desktop and in mobile view, including keyboard-only navigation.

Known limitations

The screen illustrations on the home page are for illustration only and are hidden from screen readers; everything they show is also written in the text beside them. This statement covers the website. If you run into an accessibility problem in the app itself, please let us know and we'll fix it.
