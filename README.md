# אתר Arnaki

אתר סטטי (HTML + CSS, בלי שרת ובלי ספריות) שמתאר את Arnaki ועומד בדרישות של Apple להרשמת ארגון ולהגשת אפליקציה: מדיניות פרטיות, תנאי שימוש, עמוד תמיכה, מחיקת חשבון, והצהרת נגישות לפי הדין הישראלי. עברית כברירת מחדל, אנגלית תחת `/en/`.

| עמוד | כתובת | שימוש |
|---|---|---|
| בית | `/` · `/en/` | Marketing URL ב-App Store Connect |
| מדיניות פרטיות | `/privacy/` · `/en/privacy/` | **Privacy Policy URL (חובה)** |
| תמיכה | `/support/` · `/en/support/` | **Support URL (חובה)** |
| תנאי שימוש + תנאים למוכרים | `/terms/` · `/terms/#sellers` | קישור מההרשמה ומאימות המוכר באפליקציה |
| מחיקת חשבון | `/delete-account/` | הסבר משלים למחיקה באפליקציה |
| הצהרת נגישות | `/accessibility/` | חובה לפי תקנות הנגישות |

## בנייה
```bash
node build.mjs
```
התוצאה בתיקייה `dist/`, והיא מה שעולה לאוויר. כל פרטי החברה נמצאים ב-`site.config.json` בלבד. שדה ריק מוצג באתר כסימון צהוב "להשלמה", והבנייה מדפיסה אילו שדות חסרים.

## מה צריך להשלים לפני עלייה
1. **ב-`site.config.json`:** מספר חברה (ח.פ.), כתובת רשומה בעברית ובאנגלית, שם וטלפון של רכז/ת הנגישות.
2. **תיבות מייל:** `support@`, `privacy@`, `accessibility@arnaki.app`. הכי פשוט: Cloudflare Email Routing, שמעביר את המיילים לתיבה הקיימת בחינם.
3. **בדיקה משפטית:** העמודים המשפטיים הם **טיוטה** ומציגים באנר "טיוטה לבדיקה משפטית". אחרי שעורך הדין מאשר, קובעים `"legalApproved": true` ובונים מחדש. שאלות לעורך הדין:
   - גיל מינימלי 18 (או 16)?
   - שמירת מידע 30 יום אחרי מחיקת חשבון.
   - חובות לפי תיקון 13 לחוק הגנת הפרטיות: רישום מאגר, ממונה על הגנת הפרטיות.
   - העברת מידע לחו"ל. צריך לאמת את אזורי השרתים של Railway ושל MongoDB Atlas.
   - ניסוח "החברה אינה צד לעסקאות" בשוק ההחלפות, מול חוק הגנת הצרכן.
   - סעיף "הנוסח העברי גובר".
4. **אחרי האישור של Apple:** להכניס את קישור האפליקציה ב-`appStoreUrl`, והכפתור יהפוך ל"להורדה". מומלץ להחליף אותו בתג הרשמי "Download on the App Store" מ-Apple Marketing Resources.

## הבטחות באתר שחייבות להיות נכונות ביום העלייה
האתר מתאר את גרסה 1 כפי שתושק. כל שורה כאן היא משימה בתוכנית:
- [x] מחיקת חשבון מתוך האפליקציה (פרופיל ← מחיקת חשבון)
- [ ] "שכחתי סיסמה" במסך הכניסה
- [ ] מספרי כרטיסים וקודים מוצפנים גם בכרטיסים ישנים (הרצת ההצפנה לכרטיסים הישנים)
- [x] מספרי כרטיסים לא נחשפים למשתמשים אחרים (trending/popular, הצעות)
- [x] אין שמירת מספרי כרטיסי אשראי (הסרת `/api/credit-cards`)
- [x] מספר הטלפון לא מוצג בצ'אט אלא אם המשתמש בחר לשתף (כפתור WhatsApp לפי בחירה)
- [x] אין בקשת מיקום (מעבר לזיהוי אזור לפי הגדרות המכשיר)
- [x] אישור מוכר: שם מלא + התנאים למוכרים (סעיף 7) מוצגים באפליקציה עם קישור לתנאים המלאים
- [ ] דוחות קריסה מסננים פרטים אישיים (Sentry)
- [x] אישור תנאים בהרשמה, כולל גיל 18 (השרת שומר `termsAcceptedAt` ו-`termsVersion`)
- [x] דיווחים נבדקים תוך 24 שעות (תור דיווחים לאדמין)

**הטקסטים המשפטיים מופיעים גם בתוך האפליקציה** (במאגר `PayzoTest`: `PayzoApp/frontend/content/legal.ts`, עברית ואנגלית). כל שינוי בעמודי `privacy` ו-`terms` כאן חייב להיכנס גם לשם, יחד עם עדכון `LEGAL_VERSION` באפליקציה ו-`CURRENT_TERMS_VERSION` בשרת (`payzo-backend`: `backend/utils/legal.ts`). כשעורך הדין מאשר, קובעים גם `LEGAL_APPROVED = true` באפליקציה כדי להסיר את הערת הטיוטה.

## העלאה לאוויר (GitHub Pages, חינם)
האתר מתפרסם ב-GitHub Pages דרך GitHub Actions (`.github/workflows/pages.yml`): כל push ל-`main` בונה את `dist/` ומעלה אותו. הבנייה כותבת ל-`dist/` גם `.nojekyll` ו-`CNAME` (רלוונטי רק לאירוח מענף; בפריסה דרך Actions הדומיין מוגדר פעם אחת ב-Settings ← Pages ונשמר), ומכניסה את מדיניות ה-CSP לתגית `<meta>` בכל עמוד, כי GitHub Pages לא שולח כותרות מותאמות.

**GitHub Pages בחינם עובד רק במאגר ציבורי.** לכן האתר יושב במאגר משלו, בלי קוד האפליקציה.

הגדרה חד-פעמית:
1. במאגר ב-GitHub: Settings ← Pages ← Build and deployment ← Source: **GitHub Actions**.
2. באותו עמוד, Custom domain: `arnaki.app` ← Save. אחרי שה-DNS מזוהה מסמנים **Enforce HTTPS**.
3. הדומיין `arnaki.app` נרשם ב-Cloudflare Registrar (24.09.2026), וה-DNS מנוהל שם. בעמוד הדומיין ב-Cloudflare ← DNS ← Records, במצב **DNS only** (ענן אפור, לא כתום):
   - `A` עבור `@` לכל אחת מהכתובות `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `AAAA` עבור `@` לכל אחת מהכתובות `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`
   - `CNAME` עבור `www` אל `<שם-המשתמש-ב-GitHub>.github.io`
4. HTTPS חובה בסיומת `.app` (היא ברשימת ה-HSTS preload של הדפדפנים). GitHub מנפיק תעודה אוטומטית אחרי שה-DNS מזוהה, בדרך כלל תוך דקות.
5. תיבות מייל: ב-Cloudflare, בעמוד הדומיין ← Email ← Email Routing מעביר את `support@`, `privacy@` ו-`accessibility@arnaki.app` לתיבה קיימת בחינם.

Cloudflare Pages ו-Netlify עדיין נתמכים אם אי פעם עוברים: Build `node build.mjs`, Publish `dist`, והם גם קוראים את קובץ `_headers`.

## מיתוג
- `src/assets/icon.svg`: לוגו ואייקון לאתר (פינות מעוגלות).
- `brand/app-icon.svg` + `brand/app-icon-1024.png`: **אייקון האפליקציה ל-App Store**, 1024×1024, בלי שקיפות ובלי פינות מעוגלות.

האתר לא משתמש בעוגיות, בכלי ניתוח או בשירותים חיצוניים, והגופנים (Heebo, Assistant) נשמרים מקומית. זה מה שמאפשר למדיניות הפרטיות להצהיר על כך.
